# Week 10 Assignments

This repository contains five Java programming assignments. Each question is in
its own folder and can be compiled and run independently.

| Folder | Topic | Main class |
| --- | --- | --- |
| `q1` | Find the row with the highest total in a grid | `Main` |
| `q2` | Summarize attendance and the longest consecutive streak | `Main` |
| `q3` | Rotate a roster by a specified number of positions | `QUESTION3` |
| `q4` | Count scores within an inclusive range in a sorted array | `Question4` |
| `q5` | Find the second-highest distinct score | `Main` |

## Running an assignment

Install a Java Development Kit (JDK), then open a terminal in the question's
folder. For example, to run Question 1:

```text
cd q1
javac "QUESTION 1.java"
java Main
```

Use the corresponding `.java` filename and main class from the table for the
other questions. Question 3 optionally accepts the rotation count as a command
line argument; it defaults to `2`.
